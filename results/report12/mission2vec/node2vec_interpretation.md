## 4. UMAP 시각화 해석 (umap_clusters.png)

### 4.1 전체 분포 형태

1,447건의 미션 경로가 128d 벡터에서 UMAP 2D로 투영된 결과, **호(arc) 형태의 연속 분포**를 형성한다. 이는 경로 구조가 이산적 클러스터가 아닌 **연속적 스펙트럼**을 이루고 있음을 시사한다 — 짧은 직선 비행에서 복잡한 다중 격자 수색까지 점진적으로 변화하는 구조.

### 4.2 클러스터 분포

| 클러스터 | 경로 수 | 비율 | 위치 | 해석 |
|---------|--------|------|------|------|
| Cluster 2 (주) | 1,243 | 85.9% | 호의 중앙~좌측 | 표준 비행 패턴 (다수 직선/단순 경로) |
| Cluster 0 | 26 | 1.8% | 우하단 | 특수 구조 패턴 A |
| Cluster 1 | 19 | 1.3% | 우측 끝단 | 특수 구조 패턴 B |
| Cluster 3 | 12 | 0.8% | 우하단 | 극소 특수 패턴 |
| Noise (-1) | 147 | 10.2% | 분포 주변부 | 어떤 클러스터에도 미속 |

### 4.3 이상 탐지 결과

- **빨간 삼각형 (▲)**: 합성 이상 — WP 순서 셔플. 주 분포 내 산재 → 가중 평균 풀링이 순서 변화를 흡수하여 정상과 유사한 벡터 생성
- **주황 사각형 (■)**: 합성 이상 — 좌표 노이즈 추가. 주 분포와 약간 이탈하나 극단적이지 않음
- **빨간 원 (○)**: 앙상블 기반 탐지된 이상 경로 (n=75). 주 분포의 **주변부에 집중** — 분포 끝단일수록 이상 점수 높음

### 4.4 토론

**관찰 1: 주 클러스터 집중 현상**
전체 85.9%가 단일 클러스터에 속한다. 이는 실 관제 데이터의 미션 대부분이 유사한 구조(직선 이동, 단순 격자)임을 반영한다. 소규모 클러스터(0/1/3)는 특수 임무 패턴일 가능성이 높으며, MapBox reverse geocode 보강 후 장소명과 교차하면 클러스터의 운영 의미를 해석할 수 있다.

**관찰 2: 합성 이상 탐지의 한계**
WP 순서 셔플 이상의 탐지율이 13.3%로 낮다. 이는 Node2Vec + 가중 평균 풀링이 **집합적(set-level) 표현**에 가까워 순서 정보를 충분히 보존하지 못함을 의미한다. 향후 Attention Pooling 또는 Readout 방식(Set2Set)으로 순서 민감도를 향상시킬 수 있다.

**관찰 3: 좌표 노이즈 이상의 상대적 효과**
좌표 노이즈 이상 탐지율(26.7%)이 순서 셔플(13.3%)보다 높다. 노드 피처(lat/lon/alt)에 직접 영향을 주는 노이즈가 그래프 임베딩에 더 강하게 반영됨을 보여준다. 이는 Node2Vec이 **구조보다 피처에 민감**할 수 있음을 시사하며, GNN(Graph Neural Network) 적용 시 구조적 이상 탐지가 개선될 가능성이 있다.

**관찰 4: 노이즈 포인트의 의미**
HDBSCAN 노이즈 147건(10.2%)은 어떤 클러스터에도 속하지 않는 경로이다. 이들은 **자연 발생 이상 후보**로, 앙상블 점수와 교차 분석하면 규칙 기반으로 잡지 못하는 구조적 비정상 경로를 발견할 수 있다.

## 5. enriched_routes.csv 설명

| 컬럼 | 설명 |
|------|------|
| `route_id` | 경로 식별자 |
| `wp_count` | 웨이포인트 수 |
| `total_distance_m` | 경로 총 거리 (haversine, m) |
| `avg_distance_m` | WP 간 평균 거리 |
| `max_distance_m` | WP 간 최대 거리 |
| `avg_bearing_change` | 평균 방위 변화 (°) — 높을수록 커브 많음 |
| `max_bearing_change` | 최대 방위 변화 (°) — 급커브 감지 |
| `avg_altitude_m` | 평균 고도 |
| `start_lat/lng` | 시작점 좌표 |
| `end_lat/lng` | 종료점 좌표 |
| `centroid_lat/lng` | 중심점 좌표 |
| `start_place` | 시작점 장소명 (MapBox reverse geocode) |
| `end_place` | 종료점 장소명 |
| `centroid_place` | 중심점 장소명 |

**활용:**
- `avg_bearing_change`가 높은 경로 → 격자/원형 수색 패턴 후보
- `total_distance_m` vs `wp_count` 비율 → 밀집/산개 패턴 구분
- `start_place` / `end_place` → 지역별 미션 분포 분석
- 클러스터 라벨과 교차 → 클러스터의 운영 의미 부여

## 6. 3-Method 앙상블 각 방법별 역할

| 방법 | 잡는 이상 유형 | 비중 |
|------|-------------|------|
| **Centroid Distance** | 전역 분포 이탈 — 전체 패턴과 구조적으로 다른 경로 | 30% |
| **Isolation Forest** | 고차원 특이점 — 비선형 경계에 있는 이상 | 40% |
| **KNN Average** | 로컬 밀도 이탈 — 주변 이웃이 없는 고립 경로 | 30% |

**앙상블의 의의**: 단일 방법은 특정 유형만 탐지. 전역(centroid) + 구조(IF) + 로컬(KNN) 관점을 결합하여 탐지 커버리지 확대.
