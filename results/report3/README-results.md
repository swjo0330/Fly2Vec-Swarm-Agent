## 1. Node2Vec → GCN 전환 동기

Node2Vec은 그래프 **구조(토폴로지)**만 학습하고 노드 피처(lat, lon, alt)를 무시한다.
결과적으로 "인천 송도 격자 수색"과 "충남 보은 격자 수색"이 구조가 같으면 동일한 벡터를 생성.

GCN은 message passing으로 노드 피처를 집계하여 **위치 + 구조를 동시에 학습**.

## 2. Node2Vec vs GCN 비교

| 항목 | Node2Vec (report1) | GCN (report3) | 변화 |
|------|-------------------|---------------|------|
| **클러스터 수** | 10 | **63** | 6.3배 세분화 |
| **Noise 비율** | 49.3% (986건) | **25.1% (501건)** | **24% 감소** |
| **Anomaly 평균** | 0.220 | **0.155** | 정상 경로가 더 명확히 분류 |
| **95%ile 임계값** | 0.664 | **0.481** | 더 민감한 이상 탐지 |
| **위치 구분** | ❌ 불가 | ✅ 가능 | "인천 격자" ≠ "충남 격자" |

### 해석

**Noise 49% → 25%**: Node2Vec에서 "어떤 패턴에도 안 속한다"고 판단된 경로의 절반을 GCN이 **위치 기반으로 클러스터에 편입**. 위치 정보가 추가 분별력을 제공한 것.

**63개 클러스터**: 10개에서 63개로 세분화된 것은 같은 구조라도 **지역이 다르면 다른 클러스터**로 분리되었기 때문. 이는 GCN이 lat/lon 피처를 학습한 증거.

**Anomaly 평균 하락 (0.220 → 0.155)**: 정상 경로들이 더 뚜렷한 클러스터에 속하면서 centroid 거리가 줄어든 것. 이상 경로는 여전히 높은 점수를 유지하므로 **분별력 향상**.

## 5. UMAP 시각화 해석

### 2D UMAP (umap_clusters.png)

Node2Vec의 "3개 영역 집중" 대비, GCN은 **전체 2D 공간에 분산**.

- Node2Vec: 호(arc) 형태 연속 분포 → 구조만 반영
- GCN: **점 구름(point cloud) 형태** → 위치+구조 동시 반영으로 다양한 방향에 클러스터 분포

63개 클러스터가 각각 소규모(10~75건)로 분산되어 있어, 각 클러스터가 **특정 지역 + 특정 구조의 조합**을 나타냄.

### 3D UMAP (umap_3d.html)

브라우저에서 `open results/report3/umap_3d.html`로 회전 가능.
3차원에서 2D에서 겹쳐 보이는 클러스터가 분리되는지 확인 가능.

## 7. 토론

### GCN 도입의 의의

Node2Vec이 포착하지 못한 **위치 기반 패턴 분리**를 GCN이 성공적으로 수행.
Noise 비율이 49% → 25%로 절반 감소한 것은 위치 정보(lat/lon)가 경로 분류에 유의미한 피처임을 실증.

### 한계

- **63개 클러스터가 과다 세분화일 수 있음**: 일부 클러스터는 단순히 좌표가 가까운 경로끼리 묶인 것일 수 있으며, 운영적 의미가 없는 분할일 가능성
- **비지도 학습 한계**: GCN이 학습 없이(untrained) message passing만으로 피처를 집계하므로, 학습 기반 GCN Autoencoder 대비 표현력 제한
- **소형 그래프(4~20 WP)**: GCN 2레이어로 거의 전체 그래프를 커버 — 더 큰 그래프에서의 효과 검증 필요

### 향후 방향

- MapBox 장소명 교차 분석으로 63개 클러스터에 **지역별 운영 의미** 부여
- GCN Autoencoder(학습 기반)로 표현력 강화
- Node2Vec + GCN 결과를 **앙상블**하여 구조적 이상 + 위치적 이상을 동시 탐지
