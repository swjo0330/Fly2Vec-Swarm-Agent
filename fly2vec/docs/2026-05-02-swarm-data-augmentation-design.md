## 2. 현재 합성 데이터 한계

| 한계 | 설명 |
|------|------|
| 고정 군집 크기 | 3~5대만 (실제: 1~10대+) |
| 동시 출발 | 시차 출발, 교대 비행 미반영 |
| 기하학적 오프셋만 | 지형, 기상, 통신 제약 미반영 |
| 균등 분배 | 정상:이상 = 2:2 (현실은 정상 >> 이상) |
| 단일 경로 타입 조합 | 복합 미션(격자+직선) 미포함 |
| 고도 고정 | 다층 수색 미반영 |

## 3. 증강 파이프라인 (6단계)

```
실 데이터 (2,068 경로)
    │
    ▼
[Stage 1] 기본 시나리오 (250건)
  - 1~5대 조합, 정상:이상 7:3
    │
    ▼
[Stage 2] 군집 크기 변형 (150건)
  - 2~10대, 드론 이질성 (속도/배터리 다양화)
    │
    ▼
[Stage 3] 시간축 변형 (150건)
  - 순차 출발 (5~10분 간격)
  - 교대 비행, 릴레이 교대
    │
    ▼
[Stage 4] 지형 적응 (150건)
  - 산지: 통신 차단, 선회 반경 제약
  - 해안: 배터리 1.2x 소모, 상승기류
  - 도심: LOS 제약, 충돌 위험 1.5x
  - 평야: 최소 제약, 장거리
    │
    ▼
[Stage 5] 복합 미션 (150건)
  - 격자+직선, 다층 고도, 순환+정찰
    │
    ▼
[Stage 6] 이상 시나리오 (200건)
  - 배터리 부족 귀환
  - GPS 드리프트 (점진적 10~20m 오차)
  - 기체 이탈 (제어 불능)
  - 통신 손실 복구
  - 쌍 충돌 직전 (< 2m)
  - 군집 분산
    │
    ▼
총 1,050건 증강 시나리오
  정상 ~700건 (67%) + 이상 ~350건 (33%)
```

## 4. 확장 노드 피처 (7d → 10d)

| 피처 | 설명 | 정규화 |
|------|------|--------|
| lat_norm | 위도 | (lat-35.5)/2.5 |
| lon_norm | 경도 | (lon-128.0)/4.0 |
| alt_norm | 고도 | alt/500 |
| seq_ratio | 경로 내 위치 | i/(n-1) |
| speed_norm | 비행 속도 | speed/10 |
| heading_norm | 방위각 | heading/360 |
| drone_id_norm | 드론 식별 | id/n_drones |
| **hour_norm** | 시간대 | hour/24 |
| **season_norm** | 계절 | season/3 |
| **terrain_norm** | 지형 제약 | 0~1 |

## 6. 실 데이터 파생 피처

### 미션 성공/실패 추정
- `tot_flying_dstc > 0` + `flying_misn_cmpl_yn = Y` → 성공 (~60%)
- `tot_flying_dstc = 0` → 계획만 (~40%)

### 경로 복잡도
```
route_complexity = avg_bearing_change (0~180°)
route_efficiency = start_end_dist / total_distance (0~1)
altitude_variance = (max_alt - min_alt) / avg_alt
wp_spacing_variance = var(consecutive_distances)
bearing_entropy = -Σ(p*log(p)) for bearing distribution
```

### 지역 밀도
- 100m 그리드 단위 WP 밀도
- 시간대별 비행 빈도
- enriched_routes.csv의 centroid 활용
